# Student Management System

## Project Description
The Student Management System is a Python-based project developed to manage student registration and attendance records easily.

## Project Objectives
- To register student details.
- To maintain student records.
- To manage student attendance.
- To display attendance information.

## Features
1. Student Registration
2. Student Details Management
3. Attendance Management
4. Display Student Records
5. Attendance Status

## Technologies Used
- Python
- Git
- GitHub
- VS Code

## Project Files
- `registration.py` – Used to register students.
- `attendance.py` – Used to mark and display attendance.
- `README.md` – Project documentation.

## How to Run the Project

**Step 1:** Download or clone the repository.

**Step 2:** Open the project folder in VS Code.

**Step 3:** Open Terminal and run:

```bash
python3 registration.py
```

**Step 4:** To run attendance management:

```bash
python3 attendance.py
```
